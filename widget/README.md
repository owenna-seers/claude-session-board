# 세션 위젯 (윈도우)

플러그인이 `~\.claude\session-board\sessions.json` 에 쓰는 현황을 1초마다 읽어, 늘 위에 떠 있는 작은 창으로 보여 준다.
Claude 앱이 다른 창 뒤에 있어도 보인다. 앱을 끄면 세션이 없으니 마지막 상태만 남는다.

## 빌드

윈도우 10/11 에 든 C# 컴파일러(.NET Framework 4.x `csc.exe`)만 쓴다. 따로 설치할 것 없음.

```
powershell -NoProfile -ExecutionPolicy Bypass -File widget\src\build.ps1 -Stop -Run
```

- 결과: `%USERPROFILE%\.claude\session-board\app\SessionWidget.exe` (`-Out <경로>` 로 바꿀 수 있음)
- `-Stop`: 떠 있는 위젯을 먼저 끈다(exe 가 잠겨 있으면 빌드가 안 됨)
- `-Run`: 빌드 뒤 바로 띄운다
- 아이콘 `app.ico` 가 없으면 `make-icon.ps1` 이 만든다

빌드 없이 쓰려면 GitHub Releases 의 `SessionWidget.exe` 를 받는다. 서명이 없어 처음 실행 때 SmartScreen 이 막으면 「추가 정보 → 실행」.

## 쓰기

- 머리: 「세션」 · 로그인한 계정 · 조직, 숫자 타일 셋(확인 필요 · 작업 중 · 안 읽음). 이상이 있을 때만 그 아래 한 줄(갱신 없음 · 오류 · 리마인드 지남)
- 머리 버튼(아이콘은 윈도우 기본 글꼴 Segoe Fluent Icons): 톱니바퀴 = 설정, 눈 = 지금 보는 세션으로 가기 / 올리기, 고르기, 고정, 최소화, 끄기
- **확인 필요** = 맨 위 카드: 제목 · 질문 한 줄 · 리마인드 · 메모 · 「열기 · 미루기 · 확인 끝」 버튼
- 나머지 = 앱 사이드바 섹션별 한 줄 목록(섹션 없는 세션은 맨 아래). 줄 왼쪽 점: 파랑 = 안 읽음, 주황 = 작업 중, 빈 동그라미 = 읽음. 별 = 강조, 시계 = 리마인드(빨강 = 지남), 쪽지 = 메모, 빗금 친 사슬 = 원격 제어 꺼짐. 오른쪽 끝 = 「2시간」 같은 짧은 시간(정확한 시각은 마우스를 올리면)
- 읽은 세션은 섹션마다 「읽은 것 n개 더 보기」로 접힘(강조 · 리마인드 · 작업 중 · 보는 중인 것은 늘 보임). 섹션 이름 클릭 = 섹션 접기 / 펼치기
- 줄 · 카드 클릭: Claude 앱에서 그 세션 열기(+ 읽음 표시). 확인 필요는 사용자가 내릴 때만 사라진다
- 오른쪽 클릭: 강조 · 읽음 / 안 읽음 · 미루기 · 확인 끝 · 위젯에서 빼기 · 리마인드 · 메모
- 앱 메인 창에서 포커스가 있는 세션 = 줄 바탕이 밝고 왼쪽에 가는 선(카드면 테두리)
- 위젯에 올린 세션만 본문에 나온다. 처음 보는 세션은 저절로 올림, 처음 켤 때는 그때 있는 세션 전부 올림(화면 그대로)
- Ctrl 클릭 / Shift 클릭 / 고르기 버튼: 여러 장 골라 한꺼번에. Ctrl+A 전부, Esc 풀기
- 고정 버튼: 누를 때마다 고정(늘 위 · 최소화도 막음) → 중간(늘 위 · 최소화 버튼으로만 내림) → 고정 해제(보통 창)
- 설정(톱니바퀴, 목록 자리에 열림 · Esc 로 닫기)
  - 색 테마: 부드러운 어둠(기본) · 노르드 · 그루브박스 · 모카 · 솔라라이즈드 어둠 · 솔라라이즈드 밝음 · 라테 · 종이. 오른쪽 클릭 메뉴 · 툴팁도 테마를 따른다
  - 전체 크기 90 · 100 · 110 · 125%(아이콘 · 여백까지)
  - 글씨 크기(요소별 − / +): 세션 제목 · 확인 필요 질문 · 시간 · 개수 · 안내 글 · 섹션 이름 · 숫자 타일
  - 시간 표기: 줄 끝 시간 = 「7시간」 / 시각 / 둘 다, 시각 모양 = 「26-11-18 18:10:50」 / 「11-18 18:10」 / 오늘이면 「18:10」
  - 보이기: 숫자 타일 · 계정 · 원격 제어 꺼짐 아이콘 · 확인 필요 카드 버튼 · 읽은 것 접어 두기 · 갱신 시각
  - 알림: 세션이 끝나면 위젯도 알림
  - 「기본값으로」(테마는 그대로)
- 맨 아래: 「확인 끝 n」 「미룸 n」 「안 올린 것 n」(누르면 목록 맨 아래에 그 칸이 펼쳐지고 그리로 스크롤, 다 0이면 숨김) · 갱신 시각 · ? = 가이드(동작 하나당 한 줄)
- 트레이 아이콘: 클릭 보이기 / 내리기, 더블클릭 띄우기, 오른쪽 클릭 「테마」 · 「윈도우 시작할 때 같이 켜기」(HKCU Run `SessionWidget`) · 「세션이 끝나면 위젯도 알림」
- 알림: 세션이 끝날 때(답 왔음 · 확인 필요)는 Claude 앱이 알리므로 위젯은 기본으로 조용하다(트레이 메뉴에서 켬). 리마인드는 늘 소리 + 트레이 풍선

## 파일

- `widget-settings.json`(exe 옆): 창 자리 · 크기 · 고정 단계(`pinMode`) · 테마(`theme`) · 크기(`zoom`) · 화면 설정(`ui`: 글씨 크기 · 시간 표기 · 보이기) · 알림(`notifyEnd`) · 펼침 상태 · 가이드 · 본 세션 id(`knownIds`) · 접은 섹션 · 「읽은 것」 펼친 섹션
- `~\.claude\session-board\meta.json`: 강조 · 읽음 · 미루기 · 확인 끝 · 리마인드 · 메모 · 위젯에 올림(`board`) — 플러그인과 같이 쓴다
- `~\.claude\session-board\view.json`: 앱 창에서 보고 있는 세션(플러그인 대표가 1.5초마다, 바뀔 때만 씀) — 읽기만
